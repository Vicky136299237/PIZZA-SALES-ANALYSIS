This Pizza Sales Dashboard is an interactive Excel-based visualization tool designed to provide clear insights into the sales performance of Pizza World. It showcases key performance indicators such as total sales, total profit, and profit percentage, along with the top-selling size. The dashboard features various charts, including a combo chart that tracks monthly sales, profit, and profit percentage; a horizontal bar chart for comparing pizza category sales; pie charts displaying the distribution of customer types (delivery vs dining) and payment modes (cash vs online); a treemap visualizing category-wise sales distribution; and an area chart that shows daily sales trends across the week. To make the dashboard dynamic, slicers for Year, Month, Customer Type, and Payment Mode are integrated and linked to all pivot tables using Report Connections, ensuring that every chart updates instantly when a filter is applied. The design incorporates a warm, pizza-themed color palette and intuitive layout, making it easy for users to explore the data and extract meaningful insights. This dashboard is a practical tool for quick business analysis and performance tracking.
